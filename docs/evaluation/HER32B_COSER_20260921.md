# Official HER-32B on CoSER

Model: `ChengyuDu0123/HER-32B`, pinned Hugging Face revision
`43c268a673cd10ff669a0874d5ff67a5e27b72df`.

The user explicitly selected the original CoSER prompts and dataset. There is
no `actor_prompt_format` override, no HER prompt substitution, and no assistant
prefill. Only generated output is converted: remove system thinking, convert
role thoughts to brackets and actions to parentheses. Role thoughts remain
visible to the judge and hidden from other characters. Raw responses are kept.
Native Qwen thinking is disabled through `enable_thinking=false`.

Evaluation uses the existing unified runner, immutable request journal,
asynchronous derived writes and separate accounting process. No benchmark or
transport code was changed for this model. This is our GLM-judged CoSER protocol,
not an exact reproduction of the HER paper's reported score.

safetensors header must cover the full file and all indexed shards must exist.

Repository scripts keep deployment separate from evaluation:

```bash
cd /workspace/projects/public-evaluation
/opt/conda/bin/python scripts/deployment/download_her32b.py
# Requires idle GPU 0/1 and an unused port; never stops other workloads.

export HER32B_ACTOR_BASE_URL=http://127.0.0.1:8032/v1
export HER32B_ACTOR_API_KEY=local-not-required
/root/.cache/chat-model-train/eval-venv/bin/python \
  scripts/evaluation/run_public_evaluation.py \
  --env-file /workspace/.secrets/evaluation.env run \
  --config configs/evaluation/roleplay_benchmarks/historical/her-32b-coser-20260921.json \
  --run-dir /dev/shm/roleplay-evaluation/her-32b-coser-originalprompt-v1-20260921 \
  --execute
```

## Network-volume outage workaround used for this run

The persistent snapshot finished downloading, but subsequent network-volume
reads stalled, including small source and credential files. Parallel reads did
not recover it. A direct HF download into RAM completed in about 25 seconds;
all 14 RAM weight shards passed HF SHA-256 and safetensors coverage verification.
The persistent copy has not yet completed independent checksum verification.

The downloader supports `--ram-first` to avoid network-volume dependencies.
Deployment supports `HER32B_SERVICE_DIR=/dev/shm/services/her-32b`; this is the
actual service log/receipt directory for this run. The checked-in evaluation
runtime was staged at `/dev/shm/her32b-eval-runtime`. Its four frozen runtime
source hashes and all prepared benchmark-input hashes exactly match the already
prepared run. Original file bytes were retained, including line endings.
Use that runtime's existing unified entry point and
`--env-file /dev/shm/her32b-evaluation.env` to resume during the outage. The
temporary credential file has mode 0600 and is excluded from the repository.

The original `/workspace` files and downloaded weights remain in place. RAM
artifacts and any updated deployment receipts need copying to persistent storage
once reads recover; do not assume they survive machine shutdown.
