# 四套角色扮演评测：两模型试跑摘要

日期：2026-09-13。验证状态：小样本完成，非全量官方榜单复现。

## 范围与结果

两候选分别为 DeepInfra `deepseek-ai/DeepSeek-V4-Flash` 与本地 Gemma 4 12B IT 基模（无 LoRA，FP8 per-tensor）。裁判均为 DeepInfra `zai-org/GLM-5.3-Flash`。

| 评测 | 每模型范围 | DeepSeek | Gemma |
| --- | --- | --- | --- |
| CoSER | 第 0 个场景，Pride and Prejudice | 46.25/100 | 16.25/100 |
| CharacterBench | 英文提示词，13 个指标各第 0 条 | 4.0000/5 | 3.6667/5 |
| MiniMax 公开方法复现 | 一个英文种子，20 条新消息，一次重复 | 94.875/100 | 94.125/100 |
| RMT 角色一致性 CU | 33 项 | 3.9394/5 | 3.9697/5 |
| RMT 情绪理解 EC | 33 项 | 3.7273/5 | 4.3636/5 |
| RMT 情绪表达 EE | 33 项 | 4.1212/5 | 4.5758/5 |
| RMT 剧情推进 PA | 33 项 | 3.3636/5 | 3.8485/5 |
| RMT 未暴露 AI 身份 CM | 10 项 | 10/10 | 10/10 |
| RMT 偏好匹配 UPA | 2 项 | 0/2 | 1/2 |

RMT 使用 Claude 3.5 版英文数据、`single_blocks`、seed=2，共四块、33 轮、144 项评分。seed 是基于输入类别覆盖选择，不基于模型结果。MiniMax 使用 seed=42，种子 ID `en_dialogue_019`，10 次 actor 与 10 次模拟用户回复，加两条初始消息共 22 条。

固定问题的两套使用相同问题；动态对话的两套只保证初始场景相同，后续输入会随模型回复变化。没有重复采样或独立裁判验证，不据此给出总体模型排名。

## 与官方协议的区别

- CoSER 沿用固定版本官方提示词与评分，使用 GLM 作为辅助模型和裁判。候选温度为 0.7，辅助模型为 0，输出上限 8192；不是上游默认采样，也不是此前 512-token actor 实验。角色生成保留 fictional thoughts，角色间传递和评分按上游方式去除对应内容。
- CharacterBench 使用官方生成/评分模板，GLM 替代 CharacterJudge，并要求只返回整数；本次提取 JSON 的 response 字符串进入评分，与官方原脚本对象传递表示不同。各项按实际评分提示词的最高合法分归一化至 5 分，再宏平均。attribute_consistency_bot 提示词允许 5 分，但源标签最大为 4；本次不使用源标签最大值排除合法评分。此汇总不能冒充官方 gold-max 聚合。
- RMT 使用论文附录评分模板，修正 UPA 参考答案占位符；GLM 替代论文裁判。块内使用模型自己的完整历史，块间独立；不是论文的完整长对话拼接。裁判仅看到模板规定的资料、当前问题、回复及适用的参考答案，没有额外增加全部历史。未公开 SEC 数据不计分。
- MiniMax 使用官方场景种子；模拟用户、actor 包装和具体六维评分档位是本地补充。每块评分，再按 Worlds 50%、Stories 25%、Preferences 25% 聚合，不是完整 100 新消息、三次重复的正式规模。
- 普通候选温度 0.7、裁判 0、MiniMax 模拟用户 0.7、输出上限 8192。未额外设置 top_p 或思考开关。远程模型为服务商动态别名，没有不可变权重 revision。

## 服务、错误及费用

Gemma 使用单张 RTX 5090，vLLM 0.28.0、Transformers 5.10.2、64K 上下文、max_num_seqs=4。等旧任务自然完成后才切换基模；请求前核验服务身份。

DeepSeek 共 268 次调用，错误 0；268 次均有费用记录，总计 $0.03167203。Gemma 流程共 254 次尝试，其中本地 66 次、GLM 188 次；187 次 GLM 请求返回费用，总计 $0.032166785。4 次辅助请求失败均重试成功（一次超时，三次裁判输出格式不合规），最终两模型均无缺失评分。合计已返回 API 费用 $0.063838815，不含 GPU 租赁和超时可能计费。

CoSER 的 16.25 是单场景，不替代此前 Gemma 200 场景均分 48.514375。评分采用上游缺陷扣分与角色发言数补偿公式，不是直接对文本给百分制印象分。
