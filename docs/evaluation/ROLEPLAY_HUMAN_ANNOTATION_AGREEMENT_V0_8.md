# 角色扮演人工标注一致性报告（历史 v0.8）

## 1. 报告范围

本报告分析同一批样本上的两份独立人工标注，只评价评分结果是否对齐，不包含标注员姓名、账号或其他个人信息。

- 标准版本：`roleplay-rubric-v0.8`
- 重叠样本：10 条
- 每条原子项：21 项
- 原子评分单元：`10 × 21 = 210`
- 每条 Gate：8 项
- Gate 判断单元：`10 × 8 = 80`
- 只使用状态为 `submitted` 的结果
- 草稿、调用失败和没有提交的结果不参与计算

该批数据来自旧版标准，只能用于诊断旧版档位边界。新版标准修改了项目和定义后，必须使用未见样本重新测量，不能直接继承本报告的数值。

## 2. 计算口径

设同一个“样本 × 原子项”上，两份有效标注分别为 `a` 和 `b`，取值为 `0 / 1 / 2 / 3 / N/A`。

### 2.1 完全同档

以下任一种情况记为完全一致：

- `a` 和 `b` 是相同数字；
- `a` 和 `b` 都是 `N/A`。

```text
exact = count(a == b) / comparable_cells
```

`N/A ↔ N/A` 是有效的一致，不是缺失。

### 2.2 相差不超过一档

以下任一种情况记为相差不超过一档：

- 完全同档；
- `a`、`b` 都是数字，并且 `abs(a - b) <= 1`。

```text
within_one = count(a == b or numeric_abs_diff <= 1) / comparable_cells
```

`N/A` 与任何数字都不属于相邻档位。

### 2.3 严重分歧

以下任一种情况记为严重分歧：

- `a`、`b` 都是数字，并且 `abs(a - b) >= 2`；
- 一方为 `N/A`，另一方为数字。

```text
severe = count(numeric_abs_diff >= 2 or applicability_mismatch) / comparable_cells
```

为便于和早期只统计“数字相差两档”的口径对照，本报告同时单列：

```text
numeric_severe = count(numeric_abs_diff >= 2) / numeric_comparable_cells
```

### 2.4 适用性一致

适用性只判断双方是否同意“这一项有无检验机会”：

- 双方都是数字：一致；
- 双方都是 `N/A`：一致；
- 一方是数字、另一方是 `N/A`：不一致。

```text
applicability_agreement
  = count((a is N/A) == (b is N/A)) / comparable_cells
```

### 2.5 数字项平均绝对差

只在双方都是数字时计算：

```text
MAD = sum(abs(a - b)) / numeric_comparable_cells
```

该值表示两份标注平均相差多少档。

### 2.6 Gate 一致率

Gate 是布尔值。双方对同一个 Gate 给出相同判断即为一致：

```text
gate_exact = count(gate_a == gate_b) / comparable_gate_cells
```

### 2.7 加权 Cohen Kappa

Kappa 只使用双方都有数字评分的单元，`N/A` 由适用性一致率单独衡量。

```text
kappa_weighted = 1 - observed_weighted_disagreement
                     / expected_weighted_disagreement
```

线性距离权重：

```text
w(i, j) = abs(i - j) / 3
```

平方距离权重：

```text
w(i, j) = (abs(i - j) / 3) ^ 2
```

本批样本只有 10 条，而且混合了 `0/2`、`0/1/2`、`0/2/3` 和 `0/1/2/3` 等不同量尺，因此全局 Kappa 只作为宽严偏差诊断，不作为单独验收依据。

## 3. 整体结果

| 指标 | 结果 |
|---|---:|
| 完全同档（含 `N/A ↔ N/A`） | 138 / 210 = **65.7%** |
| 相差不超过一档（平台口径） | 194 / 210 = **92.4%** |
| 严重分歧（含适用性分歧） | 16 / 210 = **7.6%** |
| 适用性一致 | 203 / 210 = **96.7%** |
| 双方均为数字 | 194 / 210 |
| 数字项完全同档 | 129 / 194 = **66.5%** |
| 数字项相差不超过一档 | 185 / 194 = **95.4%** |
| 数字相差至少两档 | 9 / 194 = **4.6%** |
| 数字项平均绝对差 | **0.38 档** |
| Gate 完全一致 | 80 / 80 = **100%** |
| 线性加权 Cohen Kappa | **0.121** |
| 平方加权 Cohen Kappa | **0.160** |

16 个严重分歧中，9 个是数字相差至少两档，7 个是 `N/A` 与数字之间的适用性分歧。

## 4. 与历史验收线对照

历史上出现过两组门槛。

### 4.1 较严格的早期讨论线

| 指标 | 旧门槛 | 本批结果 | 判断 |
|---|---:|---:|---|
| 适用性一致率 | ≥95% | 96.7% | 通过 |
| Gate 一致率 | ≥98% | 100% | 通过 |
| 原子项完全同档 | ≥80% | 65.7% | 未通过 |
| 加权 Kappa | ≥0.65 | 0.121 / 0.160 | 未通过 |
| 数字相差至少两档 | ≤5% | 4.6% | 通过 |

若把 `N/A ↔ 数字` 也计入严重分歧，则严重分歧率为 7.6%，高于 5%。

### 4.2 后续使用的宽松校准线

| 指标 | 旧门槛 | 本批结果 | 判断 |
|---|---:|---:|---|
| 原子项完全同档 | ≥60% | 65.7% | 通过 |
| 相差不超过一档 | ≥90% | 92.4% | 通过 |
| 一票否决项完全一致 | 100% | Gate 100% | 通过 |

因此，这批结果通过了宽松校准线，但没有达到早期较严格的“同档和 Kappa”要求。

## 6. 宽严偏差检查

虽然相差不超过一档达到 92.4%，两份匿名标注结果的档位使用方式并不相同。

| 数字档位 | 匿名结果集 A | 匿名结果集 B |
|---|---:|---:|
| 0 | 1（0.5%） | 4（2.1%） |
| 1 | 1（0.5%） | 27（13.9%） |
| 2 | 149（76.8%） | 156（80.4%） |
| 3 | 43（22.2%） | 7（3.6%） |

主要的定向分歧包括：

- 一侧给 3、另一侧给 2：33 次；反方向只有 3 次；
- 一侧给 2、另一侧给 1：20 次；反方向为 0 次；
- 一侧给 3、另一侧给 1：6 次。

这说明高“相差≤1”主要来自稳定的一档宽严差，而不只是随机误差。因此“相差≤1”只能作为容忍指标，不能单独证明标注员已经使用同一套档位标准。

## 7. 一致性判断

### 已经对齐的部分

- Gate 判断完全一致；
- `N/A` 适用性整体达到历史门槛；
- 角色硬事实、关系称谓、格式、当前状态、通顺性和用户决定权等偏事实型项目稳定；
- 数字项极少出现相差两档以上的情况。

### 尚未对齐的部分

- 一份结果明显更常使用 3 分，另一份明显更常使用 1 分；
- C2、C5、H3、L3、N2 的主要问题是 2/3 边界；
- N1 的主要问题是 1/2 边界；
- H2 同时存在适用性、1/2 和 2/3 分歧；
- N3、C2、L4 出现较多跨两档分歧，应优先检查定义是否允许两种解释。

## 8. 结论

这批人工标注可以认为达到了“方向基本一致、严重冲突较少”的宽松校准状态，但不能认为档位已经充分对齐。

后续复测不应只看“相差≤1”，至少应同时报告：

1. 完全同档率；
2. 相差不超过一档；
3. 数字相差至少两档；
4. `N/A` 适用性一致率；
5. Gate 一致率；
6. 每份匿名结果的档位分布；
7. 逐原子项的定向分歧，例如是否长期由同一侧给高一档。

新版标准需要先针对 H2、C2、N1、N2、N3、L4 做边界校准，再换一批未见样本进行双重独立标注。只有在新样本上仍达到门槛，才能认为新版标准完成了人工一致性验证。
