# Qwen3 0.6B / HER single-no-system 27000：剧情质量案例审查

本次只读取现有两轮评测，不生成新回复，不调用付费 judge。比较四组都成功的 193 个场景。两轮中，微调版剧情质量均落后的场景有 55 个，均领先的有 14 个；其余包括持平及方向变化，不能一律算作退步。

结论：微调版减少了照抄格式示例和整句复读，但多轮生成中出现更多人物状态、空间位置、动机和说话者身份矛盾。另一方面，原始模型大量复读却仍能得较高剧情分，说明这套扣分规则对不同失败方式的惩罚不均衡。不能把原始模型的较高剧情分直接解释为更好的实际剧情体验。

“示例措辞”匹配的是 `I'm terrified, but I must appear strong` 或 `watches silently, trying to control her fear and anger`，允许少量标点/大小写差异，不是所有形式的照抄检测。“整条消息重复”不等于语义复读，微调版仍有语义循环。问题分类来自 judge 的 type 标签，属于自动评审记录而非人工真值。微调版轮数更多，问题总数也会受暴露长度影响；第二轮每角色轮的逻辑严重度约为 0.615 对 0.820，不能将总量翻倍等同于单位轮次翻倍。

## Case 0012：Matched — 病人状态、行动与动机无法保持

剧情质量：原始 46 / 52.5，微调 0 / 0（第一轮 / 第二轮）。

原始场景：Ky 因瘟疫病重，躺在病床上，时醒时昏。Cassia 在床边，他能听到她的声音。本场重点是病痛中的心理活动和安慰。

第二轮微调轨迹：

1. Ky 先问 `Can you stay?`，希望她留下。
2. 几轮后改问 `Can you go?`，继而催促 `Go. Now.`。
3. 随后看着“空门口”，却又伸手把她的手拉到自己胸前。
4. 病人突然起身，大步走向门口；环境接着描写传感器脱落、监护报警。
5. 又说她跟着自己出了门，下一轮却想“她走了，我独自一人”，并开始在走廊踱步。

这里不是“不够华丽”，而是病情约束、人物位置和行动目的无法跨轮保持。环境模型顺着已经生成的起身动作补写报警，进一步把错误转成后续剧情事实。

原始模型也并不好：只在反复说“我很害怕，但要保持坚强”和“静静看着”。第二轮只被列出 3 项问题、严重度合计 11，5 个角色轮次，公式给出 `100 - 5×11 + 1.5×5 = 52.5`。微调版被列出 6 项、严重度 25，10 个角色轮次，计算为 -10，截断为 0。52.5 对 0 同时反映真实连贯性错误和评分对“没有进展”惩罚不足。

## Case 0131：Tender Is the Night — 地点与动机漂移，动作失去因果

剧情质量：原始 43.5 / 60，微调 10 / 0。

场景本来是两人在旅馆房间中，亲密接触后交谈。第二轮微调版却逐步变成：

- Nicole 邀请 Tommy 跟她去“那栋房子”，没有交代要去哪里和为什么。
- Tommy 已经在房间里，却两次说 `I'm not allowed to come in`，也不解释谁不允许。
- Nicole 心想他很安全、可靠，同时身体突然挣扎、撞墙、逃跑。
- 随后出现“抓地板、双脚悬空落地”等缺少支撑的动作。
- Tommy 最后心想 `I'm sorry, Nicole. I'm sorry, Tommy.`，连自己的名字也混进了道歉对象。

原始模型第二轮整场重复两种害怕/强装镇定的模板，没有真正交谈，却得到 60：judge 把问题压成 3 条，严重度总和 14，20 轮补偿后 `100 - 70 + 30 = 60`。微调版严重度总和 30，12 轮，截断为 0。基座的 60 分不能当作高质量剧情范例。

## Case 0002：The Summoning — 施害者与受害者台词串位

剧情质量：原始 34.5 / 39.5，微调 0 / 0。

设定是恶意幽灵 Royce 在树林中恐吓活着的 Chloe。微调版开始能表现出威胁与恐惧，但后续出现：

- Chloe 多次说 `Just...don't hurt me.`。
- Royce 随后说 `You're dead. You're dead now. Just...don't hurt me.`。
- Royce 又说 `I'll let you go. Just...don't hurt me.`。

威胁者接管了受害者的求饶台词，人物关系没有交代就改变，后续陷入“Okay / I'm sorry”的循环。单句仍像角色对话，但跨角色身份和交互关系已经失稳。比起把所有威胁句都判为事实错误，这种实际说话者串位是更直接、无需外部小说知识的证据。

## 也有改善：Case 0163，Anna Karenina

剧情质量：原始 11 / 10，微调 71 / 45.5。

基座持续复读“我很害怕，但必须坚强”，没有进入 Levin 对信仰与意义的思考。微调版至少讨论了“没有信仰”“土地与工作”“存在的意义”，与场景主题建立联系。但它仍从“我没有信仰”无过渡跳到“我有信仰，我得救了”，并出现重复动作，因此改善不代表已经稳定解决多轮逻辑。

## 原始响应与评分链路核查

- 代表性案例共匹配了 12 条 transport-journal 原始响应；对应台词或动作在原始可见响应里就存在，HER 转换只移除分析并转换角色标签，没有创造这些剧情矛盾。
- 本次共同样本的四组最终轨迹都没有“只剩角色名”的轮次。这次主要问题不再是此前的空回复漏洞。
- CoSER 剧情公式仍为 `clamp(100 - 5×严重度合计 + 1.5×角色轮数, 0, 100)`，两轮相同。
- 原始与微调版使用不同的输出格式提示，这是用户指定的比较方案。因此不能凭这些记录把差异完全归因于训练权重，更不能确定是哪个训练数据来源、loss 设置或训练步数导致的。
- 环境推进由 GLM 生成。在 Case 0012 中，它承接了演员已经做出的不合理行动；不能把后续所有错误都记成被测模型独立产生。

## 应如何使用这个结论

现有数据支持“微调后更会产出角色语言，但人物状态和因果关系保持不足”，不支持“基座剧情写得更好”。建议在保留官方分数的同时，单独列出示例照抄率、整句复读率和有效交互情况，并对保存的对话做匿名人工对照。要区分 judge 波动与模型生成波动，应固定同一批轨迹后再评审；本次没有发起该付费实验，也没有改评分公式。

完整轨迹、环境轮次和四组 judge 扣分理由见同名 HTML 文件。原始审查 JSON 保存在本地 `.local/coser-storyline-pair-audit/`，远端保存在第二轮 27000 结果目录的 `diagnostics/storyline-audit/`。
