ATOMIC SCORE AGREEMENT

原子评分一致率

N/A 是有效判定，会参与所有一致率计算；N/A 与数字评分属于严重分歧。调用失败、未完成或没有评分是“缺失”，不是 N/A，只从对应单元排除，不影响其余有效模型互相比较。

全体同档（严格）：同一单元中所有所选模型都有结果，并且给出完全相同的值；缺失单元不进入该指标分母。 全体最大档差≤1（严格）：同一单元中所有所选模型都有结果，且最高与最低数字评分最多相差一档；全体都是同一个 N/A 也计入，N/A 与数字混用不计入。 两两同档：所有有效模型对中，分数完全相同的比例。 相差≤1（含同档）：完全同档（包括 N/A↔N/A），或两个数字只差一档；N/A 与数字不属于相邻。 严重分歧：数字相差两档及以上，或一方 N/A、另一方为数字。 Token 概率修正距离：只在渠道返回该项全部合法档位（包括适用时的 N/A）的 logprobs 时计算；先把档位距离归一化到 0–1，再乘以双方所选分值概率的几何平均。只返回选中 Token 或部分档位时记为不可用，页面同时保留同一子集的原始距离。
