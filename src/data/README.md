## 目标

把明确来源的原始数据转换为有版本、可校验、可供训练或评测消费的数据资产，并保留完整 lineage、schema、统计和 manifest。

## 负责范围

- 数据源适配、快照和版本标识；
- 清洗、规范化、去重、过滤、采样和切分；
- schema、字段语义、质量规则和泄漏检查；
- manifest、统计摘要、hash 与产物位置；
- 可重复执行的 pipeline 和最小脱敏测试样例。

## 不负责

- 模型优化器、训练循环和 checkpoint；
- 正式 benchmark 的指标实现；
- 在 Git 中存放生产聊天正文或大型数据文件。

## 预期契约

每个正式数据版本至少应提供：

- 稳定的数据版本 ID，已有版本不可原地覆盖；
- 输入来源、时间窗口、许可/隐私说明；
- 输出 schema、记录数、分片数和内容 hash；
- 执行配置、代码 commit、随机种子和生成命令；
- 质量检查结果及已知偏差；
- 训练集、验证集和测试集的隔离策略。
